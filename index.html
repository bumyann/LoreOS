    // LoreOS — Quick Reference

    📖 Lorebook
    • Import — loads any ST-format lorebook JSON
    • Merge — cherry-pick entries from a second lorebook
    • Library — save/load named lorebook snapshots
    • Templates — reusable entry content snippets
    • Find & Replace — regex-capable, scoped by field
    • Export JSON — ST-compatible output
    • Export Text / Public — strips XML tags & code blocks
    • ⛶ expand — opens any textarea fullscreen
    • Ctrl+T — open template library from any field
    🎭 Character
    • Import JSON or PNG — reads card data from tEXt chunk
    • Export PNG — embeds card JSON into your image
    • Image upload — set a base image for PNG export
    • Attach Lorebook — embeds a lorebook as character_book (ST reads this on import)
    • 🔤 Pronouns & Nouns — convert pronouns to ST macros OR swap to he/him · she/her · they/them directly. Noun converter handles gendered nouns (brother↔sister↔sibling, etc.). Verb agreement auto-applied.
    • Templates — field snippets for descriptions, system prompts etc.
    • Supports V2 and V3 card spec
    ⚙ Preset
    • Import — loads any ST chat completion preset JSON
    • Prompt Library — contains ST system anchors (main, chatHistory, worldInfoBefore etc.) + your saved prompts
    • + New Prompt — adds blank to top of list
    • Search — sticky bar, searches name + content, ↑↓ to cycle
    • 🔡 Variables — scan for {{setvar::name::value}}, rename across all prompts
    • Drag rows to reorder; ▶/▼ to collapse nodes
    • Export preserves full ST format incl. prompt_order
    ✦ General
    • ◑ — toggle dark/light mode
    • ⚙ — customise colours, title, save named themes
    • Ctrl+D — toggle theme from anywhere
    • Ctrl+T — open template library
    • All data stored in localStorage — nothing leaves your browser unless you enable Gist Sync
    • ☁ Gist Sync (Settings) — sync all data across devices via a private GitHub Gist using a PAT (gist scope only)
    • Single HTML file — works fully offline
    • Mobile-friendly — swipe right from edge to open sidebar
    LoreOS // Universal Editor — built for SillyTavern, JanitorAI & SaucepanAI workflows
